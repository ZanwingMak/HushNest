有些边界，
我们想说清楚。

锁屏和切换应用后还能提醒吗？

播放实际可听的助眠音时，应用支持后台音频，并允许与其他应用混音。但其他应用、来电、系统资源限制或强制关闭仍可能中断播放；中断后需手动恢复。请先在你的 iPhone 和耳机上用短计时验证。

不播放助眠音时呢？

开始前会二次确认。没有持续播放的音频时，iOS 可能挂起应用。你可以选择继续，应用保留尽力预约及可选无声到点通知，但不能保证锁屏后耳机响铃或震动。通知也可能被专注模式隐藏。

AirPods 联机了，为什么还需要选择输出？

蓝牙联机不一定意味着媒体输出已切到耳机。点首页耳机卡片刷新，或打开系统输出选择器选中 AirPods。若耳机仍在 Mac 上播放，可确认后尝试连接：最多等待 12 秒，确认实际耳机路由前保持无声，成功后仅在耳机内播放两秒轻柔音乐。这可能暂停其他媒体；切换由 iOS 控制，无法保证成功，可随时取消。降噪模式不改变媒体路由；实际音量由系统和 App 共同决定。

能自动把 AirPods 切换到通透模式吗？

当前 iOS 没有向第三方应用提供可用的公开自动切换接口。休息结束后，可长按耳机柄，或在控制中心长按音量条手动切换。耳憩不会承诺锁屏后台自动切换。

可以用自己的音乐或视频吗？

可从文件导入音频或视频，也可从相册选择视频。应用仅提取音轨，支持每个文件最多 200 MB、2 小时，最多 20 个声音。助眠音循环播放；铃声使用前 60 秒，可选择持续重复至手动停止，关闭持续响铃时最多提醒 3 分钟。不支持受保护媒体。支持简繁中文、英语、日语、韩语和西班牙语。

我的休息数据会被上传吗？

导入音轨、配置与最近最多 365 条记录保存在本机，无分析或广告 SDK。自愿赞助由 Apple StoreKit 处理。官网由 GitHub Pages 托管，其访问日志适用 GitHub 隐私政策。
