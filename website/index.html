有些边界，
我们想说清楚。

各个平台都需要耳机吗？

iPhone 会检查实际耳机输出。Android 使用原生路由校验，蓝牙设备需要确认类型。Windows / macOS 将音频固定到当前输出，自动识别不准时会二次确认；没有可用输出时不能继续。Web 不检测耳机，也不要求确认，可能通过扬声器播放。

有线耳机能自动识别吗？

取决于系统与声卡驱动是否提供正确的端点或插孔状态。某些电脑始终把 3.5 mm 插孔报告为“扬声器”，桌面版会请你确认实际已连接耳机。确认只对当前输出及本次运行有效，切换设备或重启后需重新确认。

锁屏、最小化后还能提醒吗？

iPhone 播放可听助眠音时支持后台音频；暂时中断后会尝试恢复并重新核验耳机，系统不允许时需要手动继续。Android 使用前台服务，但电池管理或来电仍可能中断。桌面休息期间会保持电脑唤醒，最小化或收至托盘可继续计时；退出或重启后需手动恢复。Web 需要页面与设备保持可运行，锁屏和后台提醒不可靠。

不播放助眠音时呢？

iPhone 会提示锁屏风险：没有持续音频时，iOS 可能挂起应用，不能保证后台响铃或震动。Android 与桌面由各自后台服务计时，仍受系统中断、休眠和进程关闭影响。Web 仍需保持浏览器打开和设备唤醒。请先用短计时验证自己的设备。

怎么安装这些测试版本？

Windows 安装器默认使用当前用户的可写目录；便携版需完整解压。macOS 下载通用 DMG 后拖入“应用程序”，当前测试包未公证。Android 为调试签名 APK，可能与其他签名的旧版本不兼容。iPhone 推荐通过 TestFlight；unsigned IPA 必须自行签名。查看各平台安装说明 ↗

AirPods 联机后还需要选择输出吗？

蓝牙联机不一定意味着媒体输出已切到耳机。iPhone 可刷新耳机状态、打开系统输出选择器，或确认后尝试连接，最多等待 12 秒。切换由系统控制，可能暂停其他媒体，也可能失败。桌面可以先在系统中选择耳机再确认；网页版直接跟随系统输出。应用不会自动切换降噪或通透模式。

可以用自己的音乐或视频吗？

各平台支持从文件导入媒体，iPhone 还支持从相册选取视频。支持的媒体音轨保存在本机，每个文件最多 200 MB、2 小时，最多 20 个声音；受保护或不兼容的媒体可能无法使用。自定义闹铃使用前 60 秒。导入文件不会上传至开发者。

我的休息数据会被上传吗？

音轨、配置和最多 365 条记录保存在设备或当前浏览器中，无广告及分析 SDK。iPhone 自愿赞助由 Apple 处理。官网与 Web 版由 GitHub Pages 托管，访问日志适用 GitHub 隐私政策；应用不向开发者上传你的休息记录。查看隐私政策
