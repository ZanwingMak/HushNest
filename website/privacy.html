隐私政策

更新日期：2026 年 11 月 1 日

本政策适用于 ZHENYING MAI 开发的耳憩 HushNest iPhone、Android、Windows、macOS、Web 应用及本官网。我们不设置账号、不接入广告或分析 SDK，不建立休息数据服务器。

本机保存的信息

应用在设备或当前浏览器中保存声音、音量、时长、预设、主题、计时快照和最近最多 365 条休息记录，不向开发者上传或自动跨设备同步。可在“足迹”中清空记录，在“我的声音”中删除导入媒体。Web 使用当前网站的浏览器存储及音频缓存，清除网站数据会移除这些内容，仅移除主屏幕图标不一定清除数据。桌面卸载可能保留用户数据目录；手机卸载通常移除应用私有数据。iOS 备份由你的系统设置决定，Android 已禁用应用自动备份；用户自行设置的系统或文件备份不由应用控制。

自定义音频与视频

你可通过系统文件选择器主动选择媒体，iPhone 另支持相册选择器。应用只读取所选文件，使用媒体中的音轨，或在本机提取支持的音轨，不上传原始媒体或音轨，不扫描整个相册。导入内容及名称保存在本机，可随时在“我的声音”中删除；Web 导入内容保存在当前浏览器，不会上传至官网托管服务。

耳机与通知

原生客户端读取当前音频输出的类型、状态和显示名称，用于判断或确认输出；不读取蓝牙通讯录，不申请麦克风权限，不录音。桌面端的手动耳机确认只对当前进程和输出有效，改变输出后失效。Web 不检测耳机或读取输出设备名单，声音跟随系统设置。iOS 可选择本地无声提醒；Android 前台服务使用常驻通知维持计时，相关权限可在系统设置管理。

自愿赞助与 Apple 服务

自愿赞助仅存在于 iPhone 应用，使用 Apple StoreKit 一次性消耗型内购。Apple 处理付款、账单及退款。应用在设备上验证交易标识、商品及状态以完成交易，不接收银行卡信息，也不把交易上传到我们的服务器。Apple 可能依据其政策处理购买及诊断数据；TestFlight 亦可能向开发者提供测试反馈、崩溃和使用诊断。

参阅 Apple 隐私政策。请勿在公开反馈中提交支付信息或其他敏感个人资料。

官网与外部链接

官网及 Web 在线版使用 GitHub Pages 托管，不设置分析代码、追踪 Cookie、广告或表单。Web 版的配置、导入内容、休息记录及已使用音频通过浏览器本地存储和 service worker 缓存保存，这些本地内容不作为追踪用途。访问网站时，GitHub 可能处理 IP 地址和技术访问日志。访问 GitHub、Apple 或 TestFlight 链接适用对应服务的隐私规则。参阅 GitHub 隐私声明。

儿童、变更与联系

应用不会主动收集任何用户（包括儿童）的个人信息。未成年人购买赞助应取得监护人同意，并使用 Apple 家庭购买控制。如数据处理方式发生变化，本页会更新日期和内容。

如有隐私问题，请通过 GitHub Issues 联系开发者。由于休息数据仅在你的设备上，我们无法替你读取或恢复这些数据。
