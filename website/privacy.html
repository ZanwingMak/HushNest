隐私政策

生效日期：2026 年 10 月 21 日

本政策适用于 ZHENYING MAI 开发的耳憩 HushNest iPhone 应用及本官网。我们不设置账号、不接入广告或分析 SDK，不建立休息数据服务器。

本机保存的信息

应用使用本地存储保存声音、音量、时长、预设、主题、进行中的计时快照，以及最近最多 365 条休息记录。这些信息不由我们上传。你可以在“足迹”中清空记录；卸载应用会删除其本机数据。设备备份由你的 Apple 备份设置决定。

自定义音频与视频

你可以通过系统文件选择器或相册选择器主动选择媒体。应用只读取所选文件，并在本机提取音轨用于助眠和提醒，不上传原始媒体或音轨，不扫描整个相册。导入后的音轨与名称保存在应用沙盒，可在“我的声音”中删除。卸载应用会删除这些本机文件；系统备份是否包含它们由你的 Apple 备份设置决定。

耳机与通知

应用读取当前音频输出的类型和显示名称，用于判断是否可播放耳机音频；不读取蓝牙通讯录，不申请麦克风权限，不录音。通知为可选权限，仅发送本地无声提醒，你可在系统设置撤回权限。

自愿赞助与 Apple 服务

赞助使用 Apple StoreKit 一次性消耗型内购。Apple 处理付款、账单及退款。应用在设备上验证交易标识、商品及状态以完成交易，不接收银行卡信息，也不把交易上传到我们的服务器。Apple 可能依据其政策处理购买及诊断数据；TestFlight 亦可能向开发者提供测试反馈、崩溃和使用诊断。

参阅 Apple 隐私政策。请勿在公开反馈中提交支付信息或其他敏感个人资料。

官网与外部链接

官网使用 GitHub Pages 托管，不设置分析代码、追踪 Cookie、广告或表单。访问网站时，GitHub 可能处理 IP 地址和技术访问日志。访问 GitHub、Apple 或 TestFlight 链接适用对应服务的隐私规则。参阅 GitHub 隐私声明。

儿童、变更与联系

应用不会主动收集任何用户（包括儿童）的个人信息。未成年人购买赞助应取得监护人同意，并使用 Apple 家庭购买控制。如数据处理方式发生变化，本页会更新日期和内容。

如有隐私问题，请通过 GitHub Issues 联系开发者。由于休息数据仅在你的设备上，我们无法替你读取或恢复这些数据。
