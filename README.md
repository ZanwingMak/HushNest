# 耳憩 HushNest

免费开源的原生 iPhone 耳机休息闹钟。给自己片刻安静，把提醒留在耳机里。

[官网](https://zanwingmak.github.io/HushNest/) · [TestFlight](https://testflight.apple.com/join/cmFcXrjy) · [下载源码与自行签名安装包](https://github.com/ZanwingMak/HushNest/releases) · [隐私政策](https://zanwingmak.github.io/HushNest/privacy.html) · [服务条款](https://zanwingmak.github.io/HushNest/terms.html)

## 功能

- 秒级倒计时、指定时间，默认 15 / 30 / 45 / 60 分钟预设，自定义时长可保存。
- 8 种原创离线助眠音与 14 种唤醒铃声，耳机内试听及实时音量调整。助眠音最低 1%，也可选择无助眠音。
- 可开启持续响铃，重复直到手动结束或稍后提醒；关闭时最多提醒 3 分钟。支持可选震动。
- 从文件导入音频或视频，或从相册选择视频，在本机提取音轨。每个文件最多 200 MB、2 小时，最多保存 20 个；自定义铃声使用前 60 秒。
- 检查真实耳机媒体输出。可确认后尝试将 AirPods 切至 iPhone，最多检测 12 秒，成功后在耳机中播放两秒轻柔提示音。
- 四套主题，支持大字体、深色模式和减少动态效果。
- 简体中文、繁体中文、英语、日语、韩语、西班牙语。四档赞助商品均配置六语言名称与说明。
- 配置、导入音轨与最多 365 条休息记录仅保存在本机。无广告、无分析 SDK、无需账号或麦克风。

所有功能免费。茶、咖啡、甜点、小花园是四个可重复购买的一次性赞助金额，没有订阅或功能等级。实际价格以当地 App Store 和 Apple 支付确认页为准。赞助由 StoreKit 处理。

## 使用须知

开始前连接耳机，并先用短计时确认实际表现。扬声器、AirPlay、车载及混合输出不会用于开始提醒。耳机断开会停止声音；响铃期间重连后尝试续响，限时模式只在三分钟窗口内续响，持续模式继续等待手动停止。

播放可听助眠音时支持后台音频及与其他应用混音。无助眠音会先提示锁屏风险：iOS 可能挂起应用，因此不能保证后台响铃或震动。可选本地通知只有文字、不携带铃声。来电、其他音频、强制关闭、重启或耳机没电都可能中断提醒，不能将它作为重要事项的唯一提醒。

AirPods 设备切换由 iOS 决定，主动尝试可能暂停其他媒体，也可能失败；可使用系统输出选择器手动切换。当前没有适用的公开接口让第三方应用自动切换 AirPods 降噪或通透模式。

## 构建与测试

需要 macOS、Xcode、XcodeGen；支持 iOS 17 及以上版本。

```sh
xcodegen generate
open HushNest.xcodeproj
```

自行安装时在 Xcode 中选择自己的签名团队。仓库不包含发布密钥或签名证书。

```sh
bash scripts/test.sh
bash scripts/package.sh
```

测试覆盖倒计时、持久化、路由保护、断连续响、持续响铃、媒体导入、StoreKit 沙盒及 UI 交互。UI 自动化使用完全无声的音频替身，真实播放器测试只准备或解码资源，不输出声音。真机后台及跨设备 AirPods 行为仍需要设备验证。
